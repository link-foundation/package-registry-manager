## #80 Account-scan version sidecars

| Requirement                                                                          | Implementation                                                                                                                                                                                                                                                                                                                 | Verification                                                                                                                                                                                       |
| ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Bounded, safe collection of version sources                                          | `scan-sidecars` `versionSidecars` covers sibling `VERSION` files, CMake `file(READ ${CMAKE_CURRENT_SOURCE_DIR}/…)`, SwiftPM target `VERSION` files, Gradle properties, settings and catalogs, and `VERSION` files named by workflow commands. Collection is limited to `SIDECAR_LIMIT` (200), and paths beyond it are reported | unit tests in both ports                                                                                                                                                                           |
| Repository-relative paths, immutable ref, no execution, no external or symlink paths | Paths must match a safe relative pattern, and escaping references are `rejected`. Sidecars are fetched with exact `--match` paths at the scanned commit SHA (`head_commit`), not the moving branch                                                                                                                             | `unsafe and escaping version references are rejected` / `unsafe_and_escaping_version_references_are_rejected_not_followed`; `…agree on versions at one commit` asserts every `--branch` is the SHA |
| Local and account inspection agree on the ten-language repository                    | Go `v0.30.0` (`go/VERSION`), C++ `0.30.0` (`cpp/VERSION`) and Swift `0.30.0` in both                                                                                                                                                                                                                                           | `account snapshot and local inspection agree…` / `account_scan_and_local_inspection_agree_on_versions_at_one_commit`                                                                               |
| Missing, unreadable or truncated data keeps valid peers and stays explicitly unknown | A failed sidecar read adds `version files unavailable (…)` to `errors` and leaves the version unknown while keeping every package. A truncated tree is a repository error                                                                                                                                                      | `unreadable sidecars keep peers…`, `truncated trees surface as a repository error…` (both ports)                                                                                                   |
| Absent exact version versus older published versions                                 | `organization-scan` findings report `manifest-version-absent` with `expected_version` even when `latest_version` exists                                                                                                                                                                                                        | `an absent exact version is reported even when older versions exist` (both ports)                                                                                                                  |
